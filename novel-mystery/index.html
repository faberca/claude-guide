소설·머더미스터리 작업자용

원고와 세계관을 Claude Code로 다룰 때

설치와 기본 사용법은 첫 페이지를 따라 하세요. 여기는 원고·설정집·단서 파일을 다룰 때 자주 하는 실수와 바로 써볼 요청을 모았습니다.

소설·머미 작업할 때 특히 주의

원고 통째로 던지기

원고 전체를 한 번에 → 피드백이 넓고 얕아짐 → 어느 장면을 고칠지 흐려짐

해결: 챕터별로 나눠서 파일 저장 → "3장 읽고 피드백해줘"

"전체 피드백 줘"

범위가 넓으면 "전반적으로 좋습니다" 같은 쓸모없는 답변

해결: 관점 지정 — "복선 누락 찾아줘", "캐릭터 말투 일관성 체크해줘"

지어낸 역사를 그대로 채택

"조선 정조 시대에 비소가 유행했다" — 그럴듯하지만 지어낸 것일 수 있음

해결: "출처 URL 같이 달아줘" 습관. 근거 못 대면 지어낸 것.

세계관이 대화에만 존재

설정을 채팅으로만 주고받음 → 세션 끝나면 전부 날아감

해결: 설정집을 MD 파일로 → "world/인물.md 읽고 이 설정 기준으로 써줘"

수정을 말로만 받기

"여기 이렇게 고치면 좋겠어요" → 내가 직접 옮겨야 함

해결: "파일에 직접 고쳐줘" — Claude Code는 파일 수정이 됨

문체를 매번 다시 설명

"내 문체는 짧은 문장 위주고..." 매 세션마다 반복

해결: CLAUDE.md에 문체 규칙 적어두면 매번 자동 적용

시나리오 정합성 체크
"이 시나리오에서 단서·알리바이·타임라인 모순 찾아줘"

파일을 직접 읽고 인물별 동선·시간대 교차 검증. 구멍 자동 탐지.

소설 교정·피드백
"3장 읽고 문체 톤, 복선 누락, 캐릭터 일관성 체크해줘"

원고 파일을 통째로 읽고 구체적 라인 지적. 수정도 직접 반영.
